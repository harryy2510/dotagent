Installation scope

Options

--agents claude,codex
Choose agents.
--project
Install into ./.agentsync instead of ~/.agentsync.
--yes
No prompts. A first install also needs --agents.
--no-apply
Copy the pack, leave agent config alone.
--force
Update the pack. Replaced files are backed up.
